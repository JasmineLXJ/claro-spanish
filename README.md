# Claro · 我的西语学习手帐

中文界面的个人西班牙语学习网页，面向零基础 / A1。

- 五类语法目录、独立规则详情、关联个人笔记
- 数字与时间专项：0–100、星期、月份、课文词块；中文提示闪卡与三题应用练习，草稿刷新续练
- 场景小练习：从字幕/课程/词条/语法带入，短填空、提示记录、错题重练与自己的造句
- 分类词库、搜索、收藏、单词与例句朗读
- 分级短文、阅读点词 / 划词、生词分类收录
- 语法笔记、现在时变位、闪卡与填空练习
- 全站搜索：词汇、文章、语法、变位、字幕与学习问答
- 课程路线：A1 九个单元目录，第一课原创练习与主题/交际功能词块
- 独立学习问答分支；本机版可通过官方 Codex app-server 连接问答
- 彩色句子成分、主干/修饰切换；点词与划词收录，按词性、名词类型和动词人称筛选
- 听说工作室：逐段精听、循环变速、跟读录音、听写判分与语法手帐双向链接
- YouTube 嵌入、本地音频、SRT/VTT/JSON 字幕导入；原创 A1 示范课与 20 个语法与句型主题
- 浏览器本地保存，支持 JSON 备份与恢复
- 内置内容提供 Mónica 西班牙西语 es-ES 音频；新内容使用设备已安装的同口音西语声音，无英语回退

GitHub Pages 发布源：main 分支的根目录；.nojekyll 保证按静态文件发布。
电脑和手机的学习记录各自保存在浏览器中，暂不自动同步。
个人导入素材保存在本机，不进入公开仓库。链接提取与可选自动讲解由本机服务提供，静态部署不含后端或密钥。
