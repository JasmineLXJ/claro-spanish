# Claro · 巴塞罗那的第一杯咖啡

西语零基础主题样章：从点咖啡、付款、闲聊到自我介绍。手机与电脑均可使用。

分享地址：https://jasminelxj.github.io/claro-spanish/practice/

## 内容与交互

- 中文主题介绍，以及“课前学习”和“主动回忆”两个入口。
- 可收起的三语场景对话、语法笔记、动词变位、名词阴阳性与常用句式。
- 左右聊天气泡以 J / W 标识人物，连续发言合并，句内按西语、英文、中文排列。每句保留独立朗读按钮。
- 人工校对三语词义片段，使用轻量底色和下划线对应，点击、聚焦或悬停可同步突出同一组词义。没有直译关系的词不强行对应。
- 23 道中文写西语题，未答对或主动索取提示后，继续同一句的挖空练习。
- 忽略大小写、标点和元音重音；区分 ñ 与 n。按已收录答案判分，不使用收费 AI 服务。
- 独立答对、提示后完成和看过答案分别统计，支持继续进度与重练待巩固句子。

语音使用设备／浏览器提供的西班牙西语声音，固定首选 Mónica；没有 Mónica 时使用首个 es-ES 声音，不回退到其他地区口音。取消声音选择，语速位于“场景对话”标题旁。无法保证每台设备有 Mónica 或支持离线朗读。

## 编辑与验证

`topic-reading.js` 管理人工词义对应、对话分组和固定声音选择；`topic-data.js` 管理内容；`topic-core.js` 管理学习状态与判分；`topic-app.js` 管理页面；`topic.css` 管理样式。

本目录不需要安装依赖或构建。在这里执行 `python3 -m http.server 8766 --bind 127.0.0.1` 即可预览。执行 `node --test tests/*.cjs` 运行 19 项主题、阅读、同步及播放流程检查。

本课进度键为 `claro-barcelona-lesson-v2`，记录只在当前浏览器保存，不与个人手账记录合并。不同域名间的旧预览进度不会自动迁移。

这是公开的免费体验样章，没有账号、付款或已购权限核验。正式付费产品的题库和权限应由服务端管理；GitHub 可以继续保存代码，正式服务应选用允许商业应用的托管。
