# Claro · 巴塞罗那的第一杯咖啡

西语零基础主题样章：从点咖啡、付款、闲聊到自我介绍。手机与电脑均可使用。

分享地址：https://jasminelxj.github.io/claro-spanish/practice/

## 内容与交互

- 中文主题介绍，以及“课前学习”和“主动回忆”两个入口。
- 可收起的三语场景对话、语法笔记、动词变位、名词阴阳性与常用句式。
- 课前学习顶部可搜索五个栏目的全部内容，支持中文、西语、英文和省略元音重音；结果显示出处，可展开对应栏目并定位条目。
- 动词原形及六个人称变位可直接点击发音，自复变位按完整词组朗读；点击正在播放的词可停止。
- 语法说明按两到三个短要点呈现；全部动词统一为六个人称的对照表，原形列配中文，每个动词下方保留西语句子及中文译文。桌面并排展示六个人称；窄屏改为每组三个人称上下排版，单词不拆分，不依赖横向滚动条。
- 左右聊天气泡以 J / W 标识人物，连续发言合并，句内按西语、英文、中文排列。每句保留独立朗读按钮。
- 人工校对三语词义片段，按西语词类／短语作用固定为词类配色，在“场景对话”展开内容中展示图例和语速滑块。点击、聚焦或悬停可同步突出同一组词义；没有直译关系的词不强行对应。
- 23 句题库，每组 10 句。完成后可练习下一组；有足够新句和待巩固句时安排 6 句新内容、4 句待巩固内容，不足时补其他句子，同组不重复。待巩固句按上次练习的组次轮换，最新独立答对后转为普通复习。
- 第二等级根据整句首答逐词对齐：保留已写对且顺序正确的词，只挖错词和漏词；从已收录自然说法中选择最接近的表达。重复词按出现次数匹配，词序和多余词另做修正；填空草稿可保存。
- 忽略大小写、标点和元音重音；区分 ñ 与 n。按已收录答案判分，不使用收费 AI 服务。
- 独立答对、提示后完成和看过答案分别统计，支持继续进度与重练待巩固句子。
- 测试题干不显示括号内的限定提示；输入框只保留上方的“看中文，写出西语”。每题解析以两条要点呈现，保留句意和关键用法。结果页直接展示成绩和练习操作。
- 正确的自然表达 `Soy china, soy de Guangzhou` 和不带逗号的写法均计为独立答对。移除题干限定后，补充了相关常用说法及性别形式。

语音使用随页面提供的固定 Mónica（es-ES）音频，与旧手账的内置内容采用同样的播放方式。全部对话、测试参考句、动词原形及变位共对应 267 段音频。语速滑块位于“场景对话”展开内容中，拖动时实时调整播放速度。首次播放需联网加载音频文件。

## 编辑与验证

`topic-search.js` 管理五栏目的搜索索引；`topic-reading.js` 管理人工词义对应、对话分组；`topic-audio.js` 为音频索引；`tools/build-audio.py` 可在装有 Mónica 的 Mac 上生成音频；`topic-data.js` 管理内容；`topic-core.js` 管理学习状态、分组与自适应填空；`topic-app.js` 管理页面；`topic.css` 管理样式。

本目录不需要安装依赖或构建。在这里执行 `python3 -m http.server 8766 --bind 127.0.0.1` 即可预览。执行 `node --test tests/*.cjs` 运行 47 项主题、搜索、分组、自适应填空、旧进度迁移、同步及固定音频播放检查。

内部状态已升至 version 3。旧 version 2 会自动转为每组不超过 10 句，并保留全部已完成题目的历史、当前首答和整句草稿。旧固定空格与新空格位置不同，迁移时重置旧填空草稿。

答案库修订号为 `answerRevision: 1`。升级时重新校验本组保存的首答，将已被新答案库接受的完整首答恢复为独立答对，同时修正对应的本组统计和最新历史。正在进行的旧填空按新答案库重建一次；此后的填空草稿正常保存。

本课进度键为 `claro-barcelona-lesson-v2`，记录只在当前浏览器保存，不与个人手账记录合并。不同域名间的旧预览进度不会自动迁移。

这是公开的免费体验样章，没有账号、付款或已购权限核验。正式付费产品的题库和权限应由服务端管理；GitHub 可以继续保存代码，正式服务应选用允许商业应用的托管。
